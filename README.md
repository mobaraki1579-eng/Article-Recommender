# سیستم پیشنهاد مقاله

نویسنده: [نام خودت] | گروه 4 | گام 1

## مسئله
کاربر چند موضوع مورد علاقه‌اش را وارد می‌کند. برنامه با توجه به برچسب‌های هر مقاله، مقاله‌های مناسب را مرتب کرده و سه مورد اول را نشان می‌دهد.

## PEAS
| بخش | شرح |
|---|---|
| معیار عملکرد | تعداد مقاله‌های مرتبط در سه پیشنهاد اول |
| محیط | فهرست مقاله‌ها و موضوعات مورد علاقه کاربر |
| عملگرها | مرتب‌سازی و نمایش مقاله‌های پیشنهادی |
| حسگرها | موضوعاتی که کاربر وارد می‌کند و برچسب‌های مقاله‌ها |

## ویژگی‌های محیط
| ویژگی | مقدار | دلیل |
|---|---|---|
| قابل مشاهده بودن | جزئی | برنامه فقط موضوعات واردشده و برچسب‌های ثبت‌شده را دارد. |
| تعداد عامل‌ها | تک‌عامله | پیشنهادها را فقط همین برنامه تولید می‌کند. |
| قطعی بودن | قطعی | برای داده‌های ثابت، امتیاز هر مقاله ثابت است. |
| نوع تعامل | اپیزودیک | هر جست‌وجو مستقل از جست‌وجوی قبلی است. |
| تغییر محیط | ایستا | فهرست نمونه در طول اجرا تغییر نمی‌کند. |
| نوع مقادیر | گسسته | مقاله‌ها و برچسب‌ها تعداد مشخصی دارند. |

## چالش انتخابی: شروع سرد
اگر مقاله‌های کمی در فهرست باشند یا مقاله تازه‌ای برچسب نداشته باشد، پیشنهادها محدود می‌شوند.

## اجرا
در محیط Python کتابخانه‌های `numpy` و `matplotlib` و `scikit-learn` را نصب کنید. سپس سلول‌های `check_env.ipynb` و `recommender.ipynb` را اجرا کنید.
