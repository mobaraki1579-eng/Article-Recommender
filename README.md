# سیستم پیشنهاد مقاله

نویسنده: هادی مبارکی | گروه 4 | گام 1

## مسئله
کاربر چند موضوع مورد علاقه‌ اش را وارد می‌کند. برنامه با توجه به لیبل های هر مقاله مقاله‌ های مرتبط را مرتب می کند و سه مورد اول را نشان می‌دهد.

## PEAS
| بخش | شرح |
|---|---|
| معیار عملکرد | تعداد مقاله‌ های مرتبط در سه پیشنهاد اول |
| محیط | فهرست مقاله‌ ها و موضوعات مورد علاقه کاربر |
| عملگرها | مرتب‌ سازی و نمایش مقاله‌ های پیشنهادی |
| حسگرها | موضوعاتی که کاربر وارد می‌کند و لیبل های مقاله‌ ها |

## ویژگی‌های محیط
| ویژگی | مقدار | دلیل |
|---|---|---|
| قابل مشاهده بودن | جزئی | برنامه فقط موضوعات وارد شده و لیبل های ثبت‌ شده را دارد. |
| تعداد عامل‌ ها | تک‌ عامله | پیشنهاد ها را فقط همین برنامه تولید می‌کند. |
| قطعی بودن | قطعی | برای داده‌ های ثابت امتیاز هر مقاله ثابت است. |
| نوع تعامل | اپیزودیک | هر جست‌وجو مستقل از جست‌وجوی قبلی است. |
| تغییر محیط | ایستا | فهرست نمونه در طول اجرا تغییر نمی‌ کند. |
| نوع مقادیر | گسسته | مقاله‌ها و لیبل ها تعداد مشخصی دارند. |

## چالش انتخابی: شروع سرد
این مشکل زمانی پیش میاد که تعداد مقالات کم باشد یا یک مقاله جدید هنوز برچسب موضوعی نداشته باشد. در این شرایط، سیستم نمی‌ تواند مقاله‌ های مرتبط را به‌ خوبی تشخیص دهد و ممکن است پیشنها دهای مناسبی به کاربر ندهد.
برای حل این مشکل میشه تعداد مقالات را افزایش داد و هنگام اضافه‌ کردن هر مقاله لیبل های مرتبط با آن را مشخص کرد.
